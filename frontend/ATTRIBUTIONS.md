# Asset attributions

The pixel-art files in [`public/assets`](./public/assets) were supplied as
part of the Monster Tamers frontend draft and are used unchanged. They are
referenced locally by the UI; no external asset or runtime API request is
required.

The asset set includes the logo, navigation icons, scene/background layers,
monster sprites, encounter art, and avatars. If an asset is replaced or a
third-party asset is added, record its creator, source URL, and license in
this file before use.
