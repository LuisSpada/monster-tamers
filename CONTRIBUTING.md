# Contributing

Thank you for contributing to Monster Tamers.

## Workflow

1. Create a focused branch from `main`.
2. Keep changes limited to the relevant area.
3. Add or update documentation when behavior or project conventions change.
4. Run the applicable verification commands before opening a pull request.
5. Open a draft pull request early when feedback is useful.

The applications are not yet initialized, so project-specific build and test
commands will be documented here as the frontend and backend are added.

## Repository conventions

- Use UTF-8 encoding and LF line endings.
- Follow the indentation rules in `.editorconfig`.
- Never commit secrets, local environment files, generated output or IDE
  project configuration.
- Keep documentation under the appropriate `docs/` subdirectory.
